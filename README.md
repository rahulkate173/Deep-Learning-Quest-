# Deep Learning Quest

A practical, hands-on repository for learning deep learning, neural networks, transformers, large language models (LLMs), RLHF, and cloud-based AI experimentation.

## Why this repository exists

Deep Learning Quest is designed to help students, developers, and AI enthusiasts learn by doing. Instead of only reading theory, this repository focuses on real projects, notebooks, and experiments that demonstrate how modern deep learning systems work in practice.

The goal is simple:

- make AI learning accessible
- explain concepts through code and notebooks
- cover both fundamentals and advanced topics
- include practical LLM and RLHF workflows
- connect learning with real-world deployment on Google Cloud

## Purpose of this repository

This repository acts as a learning lab for:

- neural networks and deep learning fundamentals
- optimization techniques and model training
- generative models and GANs
- transformers and LLM basics
- model evaluation and benchmarking
- RLHF, PPO, GRPO, and alignment techniques
- Google Cloud workflows for AI and ML experiments

Whether you are a beginner starting with deep learning or an engineer exploring LLM fine-tuning and reinforcement learning, this repo is meant to be a useful reference and study companion.

## What you'll find here

This repo includes a collection of notebooks covering:

- CNNs, RNNs, Autoencoders, VAEs, and GANs
- Optimizers and training strategies
- Loss functions and regularization
- Transformers, BERT, and attention-based architectures
- LLM compression, benchmarking, and serving
- RLHF training concepts and experimentation workflows
- Qwen-style fine-tuning and alignment ideas
- Google Cloud deployment patterns for AI workloads

## Getting started

### 1. Clone the repo

```bash
git clone https://github.com/rahulkate173/Deep-Learning-Quest-.git
cd Deep-Learning-Quest-
```

### 2. Create a virtual environment

```bash
python -m venv .venv
source .venv/bin/activate
```

### 3. Install dependencies

Install the core packages you need for your chosen topic, for example:

```bash
pip install jupyterlab notebook
pip install tensorflow torch transformers datasets accelerate
```

For specific LLM or RLHF work, additional packages such as `sentencepiece`, `huggingface_hub`, and `google-cloud-storage` may also be useful.

### 4. Open notebooks and start learning

```bash
jupyter lab
```

Then open any notebook and explore the code.

## Recommended learning path

### Beginner path

1. Start with optimization and model training notebooks
2. Learn CNNs, losses, and regularization
3. Explore classification and regression examples
4. Understand model evaluation and debugging

### Intermediate path

1. Move into transformers and attention models
2. Learn BERT and LLM architecture basics
3. Experiment with model evaluation and benchmarking
4. Practice fine-tuning and optimization workflows

### Advanced path

1. Explore RLHF foundations and preference optimization
2. Learn PPO/GRPO-style experimentation
3. Run model tuning in cloud environments
4. Test checkpointing, serving, and deployment strategies
